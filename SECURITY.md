# Security Policy

## Reporting a vulnerability

Do not file security vulnerabilities as public GitHub issues or pull requests.
Use GitHub's private vulnerability reporting feature after it is enabled for
the repository, or the private contact channel configured by the owner.

**Publication blocker:** the repository owner has not supplied or enabled a
private disclosure channel. Do not publish this policy as final until that
channel is configured and tested.

Please include the affected version or commit, impact, reproduction steps that
use only a local lab, and any suggested mitigation. Do not include real
engagement evidence or secrets in a report.

## Supported versions

No public release has been designated yet. Support windows and coordinated
disclosure timelines require owner configuration.
