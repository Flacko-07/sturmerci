# Operator Guide

The maintained operational walkthrough is
[operator-guide.md](operator-guide.md). It covers tool setup, engagement and
approval workflows, scanner dispatch, evidence review, triage, findings, and
reporting. Use the installed CLI's `--help` to confirm current options.

Before each assessment, confirm written authorization, exact in-scope assets,
time window, allowed techniques, rate limits, and exclusions. Use a disposable
local lab for examples and validation. Register and verify each external tool
binary before issuing approval. Do not trust LLM triage as a finding without
human validation.

Protect evidence, audit data, database backups, and report exports as sensitive
assessment data. Follow the engagement's retention and deletion requirements.
