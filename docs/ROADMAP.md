# Roadmap

Priorities are constrained by current technical debt and publication gates.

1. Resolve source ownership/provenance, dependency licensing, tool payload
   redistribution, and knowledge-base rights before publishing a source
   release.
2. Complete independent security, egress, privileged integration, installed
   wheel, and local-lab validation.
3. Retain as deferred until separately designed and validated: kernel-level
   isolation of TLS proxy upstream connections; Class 0 fully unprivileged
   no-network execution; complete CVSS 4.0 calculation; PDF reporting; bulk
   NVD/CWE/CAPEC/ATT&CK ingestion.
4. Configure private vulnerability disclosure, GitHub repository ownership,
   project support channels, and trademark/reputation review.

The roadmap does not mark an item complete solely because documentation or a
module exists. See [TECHNICAL_DEBT.md](TECHNICAL_DEBT.md).
