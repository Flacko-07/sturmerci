# Branding Review

## Selected identity

- Product name: **Sturmer Cyber Intelligence**
- Short name: **Sturmer**
- Proposed GitHub repository slug: `sturmercyberintelligence`
- Spelling rule: use `Sturmer`; do not use diacritics.

README and package display metadata use the selected name. The Python import
package remains `sentinel`, and the `sentinel` CLI remains available for
compatibility. Database identifiers and environment variables are not changed.

## Clearance and non-affiliation

Trademark and reputation clearance is pending. No claim of exclusive
ownership, registration, or legal clearance is made. The project is not
affiliated with, endorsed by, or sponsored by BlackArch Linux. The earlier
project name could be confused with the existing BlackArch Linux security
distribution; public-facing current branding therefore uses Sturmer.

The Apache licence covers eligible source code only. It grants no right to use
the Sturmer name, logo, or other marks. Owner/legal clearance remains a release
gate.
